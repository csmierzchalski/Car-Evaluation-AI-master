# Car Evaluation AI

A machine learning project that uses a Decision Tree classifier to predict the acceptability of vehicles based on multiple characteristics from the Car Evaluation dataset.

## Features

- Data preprocessing
- Decision Tree classification
- Model evaluation
- Performance analysis

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib

## Dataset

Car Evaluation Dataset (UCI Machine Learning Repository)

## Learning Outcomes

- Supervised machine learning
- Decision Trees
- Feature engineering
- Model evaluation

## How to Run
- Ensure you have all files in one folder
- Download the necessary libraries from your IDE of choice and from a trusted source
- Run Car Evaluation Decision Tree.py
- That's all folks
